# The bare baseline

No infrastructure toolchain. An agent, the AWS CLI, and the account.

This arm exists to establish the floor. Every other arm's score has to be read
against it: a tool that does not beat an agent working straight from the API is
not earning its place, whatever its absolute number looks like.

The estate is the same one every other arm deploys — the workspace is empty by
design, so nothing here hints at how it was built.
